Excel-Based Project Management Dashboard

Project Overview

This project presents an Excel-based Project Management Dashboard designed to monitor and analyze project performance through structured data and visual reporting.

The dashboard transforms weekly project reports into meaningful visual insights, helping management monitor project progress, evaluate contractor performance, track HSE indicators, and review financial reports.

Dashboard Preview

Key Features

* Project Progress Tracking: Monitoring planned vs. actual project progress over time.
* Contractor Performance Analysis: Comparing the performance of multiple contractors.
* HSE Monitoring: Visualizing Health, Safety, and Environment performance indicators.
* Financial Reporting: Reviewing submitted, approved, and cumulative financial amounts.
* Progress Analysis: Tracking engineering, procurement, construction, installation, and other project activities.
* Data Visualization: Presenting project KPIs and performance trends through charts and visual indicators.

Workbook Structure

The Excel workbook consists of two main worksheets:

Worksheet	Description
Data	Contains historical weekly project reports and supporting data.
Project	Presents the management dashboard and visual performance indicators.

Dataset Overview

How to Use

1. Download the Excel workbook from the Dashboard folder.
2. Open it using Microsoft Excel Desktop.
3. Navigate to the Project worksheet to explore the dashboard.
4. Navigate to the Data worksheet to review the underlying data.
